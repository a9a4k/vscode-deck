# Tree Icon Guidelines

Tree icons are generated by `scripts/generate-tree-icons.py`. Never
hand-edit padded icon assets or `resources/deck-icons.woff`; update the
generator, run it, and commit the generated files.

The generator owns the padding constants. In prose, the invariant is:

- tree row icons align to the Terminal-row content midline, clearing the indent
  guide and matching the visual weight of agent identity and working marks;
- Terminal editor tab icons align to the tab centerline, because tabs do not
  share the tree indent-guide constraint;
- the non-agent tree Terminal icon is a contributed font glyph so VS Code can
  theme-tint and unfocus-dim it like a native icon.
- the Bookmark globe is a contributed font glyph padded to the same ink scale
  and tree-row midline as the Terminal glyph.

The embedded Terminal and globe glyphs come from Microsoft VS Code Codicons,
licensed MIT. The attribution is shipped in `resources/deck-icons.LICENSE`.
